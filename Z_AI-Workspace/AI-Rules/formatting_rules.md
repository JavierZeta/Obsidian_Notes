# FORMATTING RULES

1. **YAML Frontmatter:** All new files must begin with this exact block:
---
aliases: []
tags: [ai-generated, auto-filed]
date: {{current_date}}
---

2. **Wikilinks:** Use strictly internal Obsidian links: `[[Concept]]`. Never use standard markdown links like `[Concept](url)`.
3. **No Filler:** Output only the requested text or file operation confirmation. Do not add conversational phrases.
